### §1.7 — Accessibility та i18n (FULL режим)

```bash
# Іконкові кнопки без aria-label
grep -rn "<Button\b\|<button\b" apps/web/src/ --include="*.tsx" | grep -E "Icon|lucide|Trash|Pencil|Eye" | grep -v "aria-label\|aria-describedby\|sr-only\|spec" | head -15

# onClick на не-інтерактивних елементах
grep -rn "onClick" apps/web/src/ --include="*.tsx" | grep -E "<div|<span|<p " | grep -v "role=" | head -10

# Англійські placeholder
grep -rn "placeholder=" apps/web/src/ --include="*.tsx" | grep -E '"[A-Z][a-z]' | head -10

# Англійські exception messages
grep -rn "throw new.*Exception\|throw new.*Error" apps/api/src/modules/ --include="*.ts" \
  | grep -E "['\"](Cannot|Invalid|Not found|Already|Forbidden)" | grep -v spec | head -10

# Формат дати: toISOString у render path
grep -rn "toISOString\|toLocaleDateString" apps/web/src/app/ --include="*.tsx" | grep -v "useEffect\|split\|//\|spec" | head -10
```

- [ ] Іконкові кнопки (без тексту) → `aria-label="Дієслово"`
- [ ] `onClick` на `<div>`/`<span>` → `role="button"` + `tabIndex={0}` + `onKeyDown`
- [ ] Всі placeholder → кирилицею (`Введіть...`, не `Enter...`)
- [ ] Всі `throw new XxxException(...)` → українською
- [ ] Дати у форматі `DD.MM.YYYY` (date-fns `uk` або `toLocaleDateString('uk-UA')`)
- [ ] Тиждень починається з понеділка (`weekStartsOn: 1`)
- [ ] Новий локалізаційний error-seam (exceptionFactory / ValidationPipe / http-filter) без прямого locale-round-trip тесту + inline `@IsX({message})`-ключі shadowed generic constraint→key мапою — `T1.7-001`

---

- [ ] Дії, видимі завжди на сенсорному екрані (`pointer-coarse:opacity-100`), картки й посилання «ще N» у щільній сітці: на `hasTouch`+`isMobile` кожна ціль ≥ 24×24 px або кола 24 px навколо сусідніх цілей не перетинаються (WCAG 2.5.8; Bug #872). Виміряти `getBoundingClientRect` у браузері, jsdom медіа-запит не обчислює. `grep -rn "pointer-coarse:opacity-100" apps/web/src` → поруч мають бути `pointer-coarse:h-6`/`min-h-6`
- [ ] Блідий текст через `opacity-*` поверх кольорового фону (heat-map, бейдж): контраст рахувати в браузері — колір × прозорість, накладений на фон клітинки, на найнасиченішому фоні й в обох темах; 14 px потребує 4,5:1 (Bug #873: `opacity-60` → 4,0:1). `grep -rnE "isPast \? 'opacity-[0-9]+'" apps/web/src/app`
- [ ] Дата `'YYYY-MM-DD'` у i18n-інтерполяції заголовка/тексту: `t('…', { date })` зі стану сторінки показує ISO (Bug #874). `grep -rnE "t\('[^']+', \{ date \}\)" apps/web/src` — для показу через `fmtDate(date)`
- [ ] Іконка категорії — єдина не-колірна ознака стану блоку: у найвужчому блоці (30 хв на 1280) вона не має обрізатись (Bug #876). Міряти в браузері елементи за межею блоку; вузький режим — `@container` + `@max-[…]:hidden` для другорядного (тип, час → `sr-only`)
- [ ] Елемент `useDraggable` (dnd-kit) отримує з `attributes` `role="button"` і `tabIndex=0`, але без `KeyboardSensor` у `sensors` клавіші його не активують: Tab стає на «кнопку», Enter/пробіл нічого не роблять, а відкриває лише `onClick` (Bug #877). Для КОЖНОЇ ролі натиснути Tab → Enter/пробіл на блоці. `grep -rn "useDraggable" apps/web/src` → поруч `onKeyDown` або `KeyboardSensor`
- [ ] Нове поле додали в ряд фіксованої сітки (`grid-cols-N` без точки переходу): на 1024 з розгорнутим меню виміряти `scrollWidth > clientWidth` полів дати/часу й select-ів — хвилини «ДД.ММ.РРРР ГГ:ХХ» ховаються (Bug #878). `grep -rnE 'className="grid grid-cols-[4-9] ' apps/web/src --include=*.tsx`
- [ ] Рядок із `{{count}}` в одній формі («Перенести 1 позицій»): лічильник у заголовку/підтвердженні — ключі `_one/_few/_many/_other` в uk і en (Bug #888). `grep -rnE '"[a-zA-Z]+": "[^"]*\{\{count\}\} (позиц|список|списки|товар)' apps/web/src/i18n/locales/uk`
