# sto-e2e — gotchas

> Частина скіла `sto-e2e`; винесено дослівно, щоб кожен файл влазив в один Read.

## Gotchas

| Проблема                                                                                          | Причина                                                                                                                                                                                                                                                                                                                                                                       | Правильне рішення                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Redirect на `/login` при тестах                                                                   | Token протух або `/auth/refresh` throttled                                                                                                                                                                                                                                                                                                                                    | `@SkipThrottle()` на refresh; не `if (auth) skip`                                                                                                                                                                                                                                                                                                                                                     |
| `networkidle` не настає                                                                           | SSE (dashboard) або TanStack polling                                                                                                                                                                                                                                                                                                                                          | Чекати конкретний UI-елемент, не `networkidle`                                                                                                                                                                                                                                                                                                                                                        |
| Element not found після `domcontentloaded`                                                        | React async fetch не завершився                                                                                                                                                                                                                                                                                                                                               | `waitFor({ state: 'visible' })` на ready-signal                                                                                                                                                                                                                                                                                                                                                       |
| `sessionStorage` не в storageState                                                                | Playwright 1.40+ потрібен патч                                                                                                                                                                                                                                                                                                                                                | setup-auth.ts явно записує sessionStorage в JSON                                                                                                                                                                                                                                                                                                                                                      |
| `serial` mode у console-errors                                                                    | Cold Next.js dev compile race                                                                                                                                                                                                                                                                                                                                                 | Не змінювати на `parallel`                                                                                                                                                                                                                                                                                                                                                                            |
| 429 на `/auth/refresh`                                                                            | Dev throttler                                                                                                                                                                                                                                                                                                                                                                 | `@SkipThrottle()` — refresh захищений cookie                                                                                                                                                                                                                                                                                                                                                          |
| Тест "проходить" але поведінка зламана                                                            | `\|\| true` або `if return` в тесті                                                                                                                                                                                                                                                                                                                                           | Видалити обхідний шлях, знайти реальний баг                                                                                                                                                                                                                                                                                                                                                           |
| `tsqd-parent-container subtree intercepts pointer events`                                         | TanStack Query Devtools FAB (bottom-left) перекриває кнопку у viewport                                                                                                                                                                                                                                                                                                        | Прибрати DevTools у E2E через `localStorage.sto_e2e_disable_devtools='1'` (setup-auth додає у storageState, QueryProvider читає)                                                                                                                                                                                                                                                                      |
| Кнопка `Новий X`/`Нове X` не знайдена                                                             | Add-button у списках перейменовано на одне слово (3785721/c3cd333)                                                                                                                                                                                                                                                                                                            | Використати `getByRole('button', { name: /^X$/ })` з exact match щоб не зловити заголовок `Xs` (множина)                                                                                                                                                                                                                                                                                              |
| Row-action button `Деталі` не знайдено                                                            | Hover-only icon Pencil з `title="Відкрити деталі"` (a5cf804)                                                                                                                                                                                                                                                                                                                  | `row.hover()` + `row.locator('button[title="Відкрити деталі"]').click()`                                                                                                                                                                                                                                                                                                                              |
| Модалка створення товару не закривається після `Зберегти`                                         | `openEditGood(newGood)` після save → reopen в edit mode                                                                                                                                                                                                                                                                                                                       | Чекати title `Редагування товару`, потім Escape з dirty-guard handling                                                                                                                                                                                                                                                                                                                                |
| Modal title тесту не з'являється після click на Tab                                               | Tab content ще не змонтований коли тест клікає `Додати`                                                                                                                                                                                                                                                                                                                       | Чекати `h2:has-text(tabName)` (section header) перед `Додати`                                                                                                                                                                                                                                                                                                                                         |
| Тест skipна́в бо немає WO/Doc/Counterparty потрібного статусу у БД                                 | seed.ts не містить кожен FSM-статус; conditional `test.skip(list.length===0)` ховає coverage gap                                                                                                                                                                                                                                                                              | Self-seeding: `beforeAll` клонує доступний DRAFT через `POST /:id/clone`, транзитить до потрібного статусу через `POST /:id/transition`; `afterAll` cleanup тільки якщо FSM дозволяє delete-шлях (`WO_DELETABLE_STATUSES`). 0 leak, deterministic coverage. (Bug #486, 231b0be2)                                                                                                                      |
| 429 ThrottlerException у `beforeAll`/тестах при login                                             | 4 workers × per-test `/api/auth/login` → throttle burst                                                                                                                                                                                                                                                                                                                       | Читати JWT з `e2e/.auth/admin.json` (globalSetup його туди вже кладе у `origins[].sessionStorage[sto_access_token]`) замість нового login                                                                                                                                                                                                                                                             |
| Чиста create-модалка НЕ закривається по Escape; спливає «Є незбережені зміни» на незайманій формі | Хибний dirty-guard: `baselineReadyRef=false`+`setTimeout(0)→true` — гонка macrotask-прапорця з відкладеним flush passive-ефектів React. Ре-рендер віддає `form` НОВИЙ reference після baseline=true → dirty-ефект `[form,lines]` спрацьовує на формі, де НІЧОГО не змінилось за значенням (Bug #644). Модалка без авто-вибору теж вражена (autoDefaultsRef-скіп не покриває). | **Це БАГ КОДУ, не тесту.** Value-based dirty: `useDirtyForm.captureBaseline(snapshot)/syncDirty(snapshot)`; модалка серіалізує значущі поля `JSON.stringify({...form, lines})` і порівнює ЗНАЧЕННЯ. Reference-only churn більше не dirty. **Діагностика:** headed-run або `page.locator('[role="dialog"]').count()` після Escape — якщо 2 dialog-и (`Новий X` + `Є незбережені зміни`) → false-dirty. |
| Edit-режим: форма dirty ОДРАЗУ з відкриття (Escape/receive не закриває)                           | Baseline захоплювався на ПОРОЖНІЙ формі: гейт `if(isEditMode && loading) return`, але `loading` стартує false, а baseline-ефект оголошено ПЕРЕД load-ефектом (passive-ефекти біжать у порядку оголошення) → baseline знято до завантаження, дані згодом → snapshot≠baseline (Bug #645)                                                                                        | **Це БАГ КОДУ.** Явний `editLoaded` state, виставлений `true` лише у load-`.finally`; гейт `if(isEditMode && !editLoaded) return`. Не залежить від порядку ефектів/початкового `loading`.                                                                                                                                                                                                             |
| Row-action тест: заповнив поле → Escape → чекає закриття модалки, але спливає guard               | Ф5 unsaved-guard: заповнення поля робить форму БРУДНОЮ навмисно → Escape коректно показує «Є незбережені зміни»                                                                                                                                                                                                                                                               | **Це ЗАСТАРІЛИЙ ТЕСТ, не баг.** Оновити: `getByRole('dialog').filter({hasText:'Є незбережені зміни'})` → click `Покинути` → тоді модалка закривається.                                                                                                                                                                                                                                                |
| Клік по рядку списку НЕ відкриває edit-модалку (dialog not found)                                 | `DetailPanelToggle` стандартно УВІМКНЕНИЙ (commit 6405c3a9/5433f932) → row-click кличе `selectPO(po)` (бокова панель), а не `setEditingXId(po.id)` (модалка)                                                                                                                                                                                                                  | **ЗАСТАРІЛИЙ ТЕСТ.** Спершу вимкнути панель: `page.getByRole('button',{name:'Сховати бокову панель'}).click()`, тоді клік по рядку → edit-модалка. Або тестувати саме бокову панель якщо це намір.                                                                                                                                                                                                    |
| Create-модалка НЕ закривається після Save (лишається «Редагування X»)                             | Навмисно: після створення картка перемикається в edit-режим (напр. counterparty commit 9d61dfaa — щоб одразу додати авто/договори)                                                                                                                                                                                                                                            | **ЗАСТАРІЛИЙ ТЕСТ.** Дочекатись заголовка «Редагування X», потім Escape (форма чиста після Save → закривається без guard), тоді продовжити пошук/verify/delete.                                                                                                                                                                                                                                       |
| МАСОВІ timeout-и: усі тести редіректять на `/login` (auth-hatch мертвий)                          | Web-dev-сервер запущено БЕЗ `NEXT_PUBLIC_E2E=1` → `E2E_HATCH_ENABLED=false` у context.tsx → `sto_e2e_skip_refresh`+ін'єкція токена ІГНОРУЮТЬСЯ → AuthProvider робить refresh-on-mount → cross-origin refresh-cookie відсутній → logout. `playwright.config webServer` вмикає прапорець, АЛЕ `reuseExistingServer:true` переюзає вже-запущений плоский dev-сервер.             | **Це dev-SETUP, не тест/код.** Перезапустити web з `NEXT_PUBLIC_E2E=1 NEXT_PUBLIC_API_URL=http://localhost:3000 pnpm --filter @sto/web dev`. **Діагностика:** standalone-скрипт `chromium` → `page.goto('/work-orders')` → якщо URL=`/login` і кнопки=`["Увійти"]` → hatch off. (T26)                                                                                                                 |
| E2E-500 на `GET /work-orders/:id` для наряду з UoM-запчастиною                                    | A1 tenant-guard ловить `goodUoM.findMany` БЕЗ orgId у detail/toDto-шляху (латентний, бо жоден тест не тягнув WO-detail з `unitOfMeasureId`-part). Модал застрягає у create-стані.                                                                                                                                                                                             | **Це БАГ КОДУ (backend).** +`orgId` у `goodUoM.findMany where` (work-orders.service findOne). Той самий клас гапу вже фіксили у fetchPartCoefficients (A3-StockEffects). **Діагностика:** API-лог `TenantIsolationError: findMany на GoodUoM без tenant-фільтра`. (52a34fc4)                                                                                                                          |
