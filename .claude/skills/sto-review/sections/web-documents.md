- [ ] E2E не відкриває картку кліком по рядку: олівець або вимкнена панель

- [ ] Картка «лише перегляд» (`deletedAt`): пройти КОЖНУ кнопку й поле, а не лише `canEdit` —

## Допоміжні переліки вікна і запити за параметром адреси (2026-10-22)

```bash
# Хуки переліків, які вікно тягне для поля (рахунки, каси, працівники) — звірити @Roles їхнього GET
# з ролями самої дії вікна
git diff <base> -- apps/web/src | grep -nE "^\+.*use[A-Z][A-Za-z]*Options\("
# Запит, увімкнений параметром адреси, який та сама сторінка прибирає з адреси
grep -rlE "searchParams\.get\('open'\)" apps/web/src/app --include=*.tsx | xargs -d '\n' grep -nE "!!(link|open)[A-Za-z]*"
```

- [ ] **Перелік для поля вікна (`GET /bank-accounts`) має ролі не вужчі, ніж дія вікна
      (`POST /payments`).** Інакше роль, яка дію має, отримує 403 на перелік: поле порожнє, «не вдалося
      завантажити», а обов'язкове поле блокує дію цілком. Ролі без переліку — запит не шлемо, значення за
      замовчуванням беремо з ендпоінта, який ця роль читає (назва з `GET /payment-methods`). Тест
      вікна мокає `useAuth` з такою роллю (`journal/web.md`, 2026-10-22, «Перелік вужчий за дію»)
- [ ] **Запит, увімкнений параметром адреси (`?open=<id>`), лишається увімкненим, доки його рядок
      у панелі, хоча параметр із адреси вже прибрано.** Вимкнений запит інвалідація після мутації не
      перечитує (`refetchType: 'active'`), і панель показує старий стан (`journal/web.md`, 2026-10-22)
